# Project Super Legacy — playtest export only

This public repository contains ONLY the Godot Web export, PWA files, and gameplay screenshots for a dedicated persistent playtest installation. The editable Godot project/source repository remains separate.

Unofficial, non-commercial, fan-made educational Dragon Ball-related game prototype. Not affiliated with or endorsed by Toei Animation, Shueisha, Bandai Namco, or the Dragon Ball rights holders. All rights in referenced franchises and footage remain with their respective owners. The prototype may be unpublished while assets/permissions are reviewed.

## Install/update
Open the GitHub Pages HTTPS site from Safari on iPhone, then Share > Add to Home Screen. Future deploys update **the same path and origin**. Save data is stored on-device by Godot, not in this repository; use the game Controls > Download Save Backup option before clearing Safari data or migrating domains. Browser storage is not a guaranteed substitute for a backup. The updater prompts you to save before reloading. Updates require publishing the newly exported build files to this repository.
